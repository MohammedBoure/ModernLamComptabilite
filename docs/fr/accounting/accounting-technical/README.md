# Documentation Comptable Technique

Cette section presente les details comptables necessaires a la comprehension des donnees conservees, des calculs, des statuts et des controles. Elle reste lisible pour la comptabilite et n'utilise pas de structure technique interne de base de donnees.

## Fichiers

| Fichier | Objectif |
| --- | --- |
| [01-data-tables.md](./01-data-tables.md) | Tableaux fonctionnels et donnees conservees. |
| [02-calculations-and-controls.md](./02-calculations-and-controls.md) | Calculs, controles, statuts et regles de verification comptable. |

## Portee

- Description des donnees comptables conservees.
- Description des calculs: differences, restes, profitabilite, salaires.
- Description des statuts: Paye, Partiel, Impaye.
- Absence de structure de base de donnees technique.

# Documentation de l'Interface

Cette section presente l'organisation des ecrans et des elements d'interface. Elle sert a aligner la vision fonctionnelle avant implementation.

## Fichiers

| Fichier | Objectif |
| --- | --- |

## Portee

- Description de la forme et de l'organisation des ecrans.
- Description des filtres, boutons, tableaux et zones de totaux.
- Absence de choix graphiques definitifs ou de details techniques de design.

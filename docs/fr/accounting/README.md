# Documentation Comptable et Administrative

Cette section s'adresse a la comptabilite, a la direction et aux ressources humaines. Elle decrit le logiciel selon trois axes: documentation generale, documentation comptable technique comprehensible par le comptable, et documentation de l'interface.

Cette section ne decrit pas la structure interne de la base de donnees ni les details de programmation. Ces elements sont reserves a la [documentation technique](../technical/README.md).

## Sections

| Section | Lien | Public | Contenu |
| --- | --- | --- | --- |
| Documentation generale | [general/README.md](./general/README.md) | Direction, comptabilite, RH | Objectif du logiciel, workflows, rapports, glossaire. |
| Documentation comptable technique | [accounting-technical/README.md](./accounting-technical/README.md) | Comptabilite et direction financiere | Donnees conservees, calculs, differences, restes, controles fonctionnels. |
| Documentation de l'interface | [ui/README.md](./ui/README.md) | Direction, comptabilite, conception | Organisation des ecrans, filtres, tableaux, boutons, totaux, impression. |

## Limites

- Description des operations visibles par la comptabilite et l'administration.
- Description des donnees conservees et des resultats calcules.
- Description de l'organisation des ecrans sans details de programmation.
- Absence de noms de tables techniques internes.

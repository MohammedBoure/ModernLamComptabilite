# 04 - Glossaire

| Terme | Signification |
| --- | --- |
| Caisse | Mouvement quotidien de l'argent. |
| Coffre | Coffre ou reserve principale. |
| Cloture Caisse | Verification ou fermeture de la caisse journaliere. |
| Montant Reel | Montant physiquement present. |
| Montant Virtuelle | Montant enregistre dans SOFTLAM ou systeme de reference. |
| Difference | Ecart entre montant reel et montant virtuel. |
| Net | Somme nette selon le contexte. |
| Caisse CV | Categorie de caisse issue du rapport initial. |
| Caisse C | Categorie de caisse issue du rapport initial. |
| TPE | Paiement electronique. |
| Remboursement | Montant rembourse ou retourne. |
| Entrees Supplementaires | Entrees additionnelles. |
| Sorties Coffre | Montants sortis du coffre. |
| Fournisseur | Fournisseur. |
| Sous-Traitant | Partenaire externe ou sous-traitant. |
| Convention | Convention. |
| Versement | Paiement ou reglement. |
| Reste | Montant restant a payer. |
| Paye | Paye totalement. |
| Partiel | Paye partiellement. |
| Impaye | Non paye. |
| Chiffre d'Affaires | Total des revenus. |
| Profitabilite | Rentabilite ou resultat apres depenses. |
| Investissements | Montants investis. |
| Bilan Mensuel | Resultat mensuel. |
| Presence | Presence du personnel. |
| Garde | Garde ou permanence. |
| Absence | Absence. |
| Conge | Conge. |
| Prime | Prime. |
| Penalite | Retenue ou penalite. |
| Avance | Avance sur salaire. |
| Salaire Net | Salaire net de base. |
| Salaire Final | Salaire final apres ajouts et retenues. |
| CNAS | Securite sociale. |
| ANEM | Agence d'emploi. |
| Etat d'Encaissement | Rapport mensuel d'encaissement. |
| Etat Cheques | Rapport des cheques. |
| Audit Log | Journal des modifications. |

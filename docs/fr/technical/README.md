# Documentation Technique

La documentation technique est divisee en deux sections independantes:

| Section | Lien | Objectif |
| --- | --- | --- |
| Specifications techniques generales | [specification/README.md](./specification/README.md) | Description technique generale: interfaces, regles, modele de donnees conceptuel, permissions, rapports et plan general. |
| Documentation d'implementation | [implementation/README.md](./implementation/README.md) | Espace reserve aux details pratiques d'implementation selon la technologie choisie. |

## Limites

- La section `specification` ne depend d'aucun framework ni langage precis.
- La section `implementation` contiendra les details pratiques: stack technique, structure du projet, schema final de base de donnees, API, frontend, tests, deploiement et configuration.
- Aucun detail d'implementation precis n'est fixe avant le choix de la technologie.

## Relation avec la documentation comptable

La [documentation comptable et administrative](../accounting/README.md) decrit le meme perimetre en langage metier. Cette section couvre les aspects techniques et d'implementation.

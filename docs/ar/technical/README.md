# التوثيق التقني

ينقسم التوثيق التقني إلى قسمين مستقلين:

| القسم | الرابط | الغرض |
| --- | --- | --- |
| المواصفات التقنية العامة | [specification/README.md](./specification/README.md) | وصف تقني عام للبرنامج: الواجهات، القواعد، نموذج البيانات المفاهيمي، الصلاحيات، التقارير، وخطة التنفيذ العامة. |
| التوثيق التنفيذي التطبيقي | [implementation/README.md](./implementation/README.md) | مساحة مخصصة لاحقا لتفاصيل التنفيذ الدقيقة حسب التكنولوجيا المختارة. |

## حدود القسمين

- قسم `specification` لا يعتمد على إطار عمل أو لغة برمجة محددة.
- قسم `implementation` يبقى مخصصا للتفاصيل العملية مثل التقنية المختارة، بنية المشروع، قاعدة البيانات النهائية، API، الواجهة، الاختبارات، النشر، والإعدادات.
- لا يتم تثبيت تفاصيل تنفيذية دقيقة قبل تحديد التكنولوجيا المستخدمة.

## العلاقة مع توثيق المحاسبة

يعرض [توثيق المحاسبة والإدارة](../accounting/README.md) نفس نطاق البرنامج بلغة وظيفية. يعرض هذا القسم التفاصيل التقنية والتنفيذية المناسبة للتصميم والبناء.

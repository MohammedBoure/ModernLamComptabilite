# 01 - Vision Generale du Produit

توثق هذه الوثيقة البرنامج على مستوى المنتج: الغرض من البناء، فئات المستخدمين، والحدود الوظيفية المتوقعة.

## الهدف

برنامج ModernLam Comptabilite هو تطبيق داخلي لمخبر ModernLam يهدف إلى استبدال جداول Excel المتفرقة بنظام واحد يجمع المحاسبة، التقارير، الموارد البشرية، والحسابات الشهرية.

البرنامج يجب أن يحقق ثلاثة أهداف رئيسية:

- إدخال العمليات اليومية بطريقة بسيطة ومنظمة.
- تحويل العمليات إلى حسابات شهرية وتقارير قابلة للطباعة.
- تقليل الأخطاء الناتجة عن تكرار الإدخال أو الحساب اليدوي.

## المستخدمون المتوقعون

| المستخدم | الدور داخل البرنامج | الاحتياج الأساسي |
| --- | --- | --- |
| Administrateur | إدارة النظام والصلاحيات | إعداد المستخدمين، فتح/غلق الأشهر، مراجعة السجلات |
| Comptable | المحاسبة اليومية والشهرية | caisse, coffre, fournisseurs, rapports |
| Caisse | إدخال الصندوق اليومي | clôture caisse, dépenses caisse, différences |
| Direction | المتابعة والقرار | dashboard, bilan mensuel, profitabilité |
| RH / DRH | تسيير الموظفين | employés, contrats, présence, congés, salaires |

## حدود النسخة الأولى

النسخة الأولى يجب أن تركز على تحويل التقرير إلى برنامج عملي، دون محاولة بناء نظام ERP كامل.

داخل النطاق:

- إدارة mois/année.
- إدخال caisse/coffre.
- متابعة fournisseurs, sous-traitants, conventions.
- حضور ورواتب وDRH.
- تقارير Etats كما وردت في التقرير.
- طباعة وتصدير PDF/Excel.
- Historique بسيط لكل تعديل مهم.

خارج النطاق في البداية:

- الربط المباشر مع البنك.
- الربط المباشر مع SOFTLAM إلا إذا توفر ملف تصدير واضح.
- محاسبة ضريبية كاملة خارج جدول encaissement.
- مخزون مخبري مفصل للمواد والréactifs.

## مبدا العمل

البرنامج يعمل بالشهر. كل شاشة تعرض بيانات شهر وسنة محددين، مع إمكانية الرجوع إلى الأشهر السابقة. عند غلق شهر، تصبح البيانات المالية الأساسية مقفلة ولا تعدل إلا بصلاحية عالية مع حفظ سبب التعديل.

تدفق البيانات العام:

1. إدخال العمليات اليومية في caisse, coffre, fournisseurs, présence.
2. حساب المجاميع والبواقي تلقائيا.
3. ظهور النتائج في dashboard والبيلان الشهري.
4. توليد التقارير للطباعة أو التصدير.
5. ترحيل البواقي والربحية إلى الشهر التالي عند الحاجة.

## هيكل الوحدات

| الوحدة | الغرض |
| --- | --- |
| Dashboard | عرض ملخص الشهر والتنبيهات |
| Comptabilite | إدخال ومتابعة caisse, coffre, dépenses, profitabilité |
| Fournisseurs | الموردون والفواتير والمدفوعات والبواقي |
| Sous-Traitants & Conventions | متابعة الاتفاقيات والمتعاملين الخارجيين |
| Presence & Salaires | الحضور، الغياب، gardes، الرواتب |
| Etats | تقارير المتابعة والطباعة |

| Administration | المستخدمون، الصلاحيات، الإعدادات، audit log |

## مبادئ واجهة الاستخدام

- الواجهة عملية ومباشرة، أقرب إلى برنامج تسيير يومي من صفحة تسويقية.
- كل شاشة تحتوي على فلاتر واضحة للشهر والسنة والحالة.
- الجداول قابلة للبحث والفرز والتصدير.
- كل عملية حفظ تعرض نتيجة واضحة: تم الحفظ، فشل الحفظ، أو توجد أخطاء يجب تصحيحها.
- الأرقام المالية تعرض بصيغة موحدة، مع تمييز المدفوع والباقي والفروقات.

## قرارات يجب تثبيتها مبكرا

- هل التطبيق Web محلي أم Desktop أم Web على شبكة داخلية؟
- هل قاعدة البيانات محلية على جهاز واحد أم مشتركة بين عدة مستخدمين؟
- هل يتم إدخال SOFTLAM يدويا أم عبر import؟
- هل يطلب النظام multi-devise أم DZD فقط؟
- هل يجب أن يكون PDF المطبوع مطابقا تماما للجداول الحالية؟

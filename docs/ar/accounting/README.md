# توثيق المحاسبة والإدارة

يجمع هذا القسم التوثيق الموجه للمحاسبة، الإدارة، والموارد البشرية. ينقسم القسم إلى ثلاثة مسارات حتى تكون القراءة مناسبة لكل حاجة: توثيق عام، توثيق محاسبي تقني مفهوم للمحاسب، وتوثيق خاص بشكل الواجهة وتنظيم عناصرها.

لا يحتوي هذا القسم على بنية قاعدة البيانات الداخلية أو تفاصيل البرمجة. التفاصيل التقنية الداخلية موجودة في [القسم التقني](../technical/README.md).

## أقسام توثيق المحاسبة والإدارة

| القسم | الرابط | الجمهور | المحتوى |
| --- | --- | --- | --- |
| التوثيق العادي | [general/README.md](./general/README.md) | الإدارة، المحاسبة، الموارد البشرية | شرح البرنامج، سير العمل، التقارير، والمصطلحات. |
| التوثيق المحاسبي التقني | [accounting-technical/README.md](./accounting-technical/README.md) | المحاسبة والإدارة المالية | البيانات التي تحفظ، الحسابات، الفروقات، البواقي، والرقابة الوظيفية. |
| توثيق الواجهة | [ui/README.md](./ui/README.md) | الإدارة، المحاسبة، التصميم، التنفيذ | شكل الشاشات، تنظيم العناصر، الجداول، الفلاتر، الأزرار، والطباعة. |

## حدود هذا القسم

- يصف العمليات كما تظهر للمحاسبة والإدارة.
- يوضح البيانات التي تحفظ والنتائج التي تحسب.
- يشرح تنظيم الواجهة دون الدخول في تقنية البرمجة.
- لا يعرض أسماء الجداول التقنية الداخلية أو تفاصيل قاعدة البيانات البرمجية.

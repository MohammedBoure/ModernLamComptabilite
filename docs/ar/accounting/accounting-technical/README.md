# التوثيق المحاسبي التقني

يعرض هذا القسم التفاصيل التقنية التي يحتاجها المحاسب والإدارة المالية لفهم ما سيحفظه البرنامج وما سيحسبه، دون الدخول في أسماء الجداول البرمجية أو بنية قاعدة البيانات الداخلية.

## الملفات

| الملف | الغرض |
| --- | --- |
| [01-data-tables.md](./01-data-tables.md) | الجداول الوظيفية والبيانات التي سيتم تخزينها. |
| [02-calculations-and-controls.md](./02-calculations-and-controls.md) | الحسابات، الضوابط، الحالات، وقواعد المراجعة المحاسبية. |

## نطاق القسم

- يشرح البيانات المحاسبية المخزنة.
- يوضح الحسابات مثل الفرق، الباقي، الربحية، والرواتب.
- يشرح حالات السجلات مثل Paye, Partiel, Impaye.
- لا يعرض بنية قاعدة البيانات البرمجية.

# 01 - نظرة عامة وظيفية على البرنامج

## الغرض

برنامج ModernLam Comptabilite هو نظام داخلي لتنظيم محاسبة وتسيير مخبر ModernLam. يحول الجداول اليدوية الحالية إلى شاشات وتقارير منظمة، مع حفظ العمليات اليومية والشهرية في مكان واحد.

## الفئات المستفيدة

| الفئة | الحاجة الأساسية من البرنامج |
| --- | --- |
| المحاسبة | تسجيل الصندوق، الخزنة، الموردين، المدفوعات، والبيلان الشهري. |
| الإدارة | متابعة رقم الأعمال، المصاريف، الربحية، والبواقي. |
| الموارد البشرية | متابعة الموظفين، العقود، الحضور، العطل، والرواتب. |
| الصندوق | إدخال clôture caisse والفروقات اليومية. |

## الوحدات الرئيسية

| الوحدة | الدور |
| --- | --- |
| Dashboard | عرض ملخص الشهر والتنبيهات المهمة. |
| Cloture Caisse | تسجيل مصاريف الصندوق وحساب الفرق بين الواقع وSOFTLAM. |
| Caisse & Coffre | متابعة حركة الصندوق والخزنة والمداخيل والمصاريف. |
| Fournisseurs | متابعة فواتير الموردين، المدفوع، والباقي. |
| Sous-Traitants & Conventions | متابعة المتعاملين الخارجيين والاتفاقيات. |
| Presence & Salaires | تسجيل الحضور وحساب الرواتب. |
| Etats | طباعة ومراجعة التقارير الرسمية. |
| DRH | إدارة الموظفين، العقود، والعطل. |

## مبدأ العمل الشهري

كل العمليات مرتبطة بشهر وسنة. يتم فتح شهر جديد، إدخال العمليات اليومية، مراجعة النتائج، ثم غلق الشهر بعد اكتمال المعطيات.

حالة الشهر تكون واحدة من:

| الحالة | المعنى |
| --- | --- |
| Ouvert | الشهر مفتوح ويمكن إدخال البيانات. |
| En revision | الشهر في المراجعة قبل الغلق. |
| Cloture | الشهر مغلق ولا يعدل إلا بتصريح خاص. |

## النتائج المتوقعة

يوفر البرنامج النتائج التالية:

- مجموع caisse الشهرية.
- مجموع coffre وصافي الخزنة.
- الفروقات بين Montant Reel وMontant Virtuelle.
- البواقي للموردين، sous-traitants، وconventions.
- البيلان الشهري.
- الربحية والربحية بعد الاستثمارات.
- تقارير الحضور والرواتب.
- Etat d'Encaissement قابل للطباعة.
- Etat Cheques وSuivi Vehicule de Service.

# 02 - سير العمل الوظيفي

## فتح شهر جديد

| المرحلة | الوصف |
| --- | --- |
| اختيار الفترة | تحديد الشهر والسنة. |
| إنشاء الفترة | إنشاء شهر عمل جديد إذا لم يكن موجودا. |
| تحميل القوائم | عرض الموظفين النشطين والموردين والمتعاملين المعروفين. |
| حالة الشهر | يبدأ الشهر بحالة `Ouvert`. |

## العمل اليومي للصندوق

| المرحلة | الوصف |
| --- | --- |
| تسجيل المصاريف | إدخال مصاريف caisse اليومية: التاريخ، التسمية، المبلغ. |
| إدخال المبلغ الحقيقي | تسجيل Montant Reel الموجود فعليا. |
| إدخال مبلغ SOFTLAM | تسجيل Montant Virtuelle القادم من SOFTLAM. |
| حساب الفرق | يحسب النظام Difference تلقائيا. |
| تبرير الفرق | عند وجود فرق، تحفظ الملاحظة المرتبطة به. |

المعادلة:

```text
Difference = Montant Reel - Montant Virtuelle
```

## متابعة caisse وcoffre

| المرحلة | الوصف |
| --- | --- |
| إدخال حركة اليوم | Caisse CV, Caisse C, TPE, depenses, remboursement, convention, sous-traitants. |
| حساب مجموع اليوم | يحسب النظام total اليوم. |
| تحديث المجاميع | يتم تحديث total, min, max, moyenne للشهر. |
| تحديث الخزنة | تؤثر المداخيل والمصاريف على Coffre Net Reel حسب القواعد المعتمدة. |

## متابعة الموردين

| المرحلة | الوصف |
| --- | --- |
| تسجيل المورد | اختيار مورد موجود أو إنشاء مورد جديد. |
| تسجيل الفاتورة أو الطلب | إدخال الفئة، المبلغ، والتفاصيل. |
| تسجيل الدفع | إدخال versement وطريقة الدفع عند وجود دفع. |
| حساب الباقي | يحسب النظام reste. |
| تحديد الحالة | Paye, Partiel, Impaye. |

المعادلة:

```text
Reste = Montant - Versement
```

## متابعة sous-traitants وconventions

| المرحلة | الوصف |
| --- | --- |
| تسجيل العملية | تحديد المتعامل أو الاتفاقية. |
| إدخال المبلغ | تسجيل montant المستحق. |
| إدخال الدفعات | تسجيل versement وطريقة الدفع. |
| حساب الباقي | حساب reste آليا. |
| ظهور التقرير | تظهر العملية في Etat Sous-Traitants أو Convention. |

## تسجيل الحضور

| المرحلة | الوصف |
| --- | --- |
| اختيار الشهر | عرض أيام الشهر والموظفين النشطين. |
| إدخال الرموز | استعمال رموز الحضور والغياب والgardes. |
| حساب المجاميع | حساب أيام الحضور، الغياب، العطل، وgardes. |
| ربط الرواتب | تستعمل المجاميع في Rapport de Salaire. |

## توليد الرواتب

| المرحلة | الوصف |
| --- | --- |
| جلب الحضور | قراءة نتائج Presence الشهرية. |
| إدخال القيم اليدوية | primes, penalites, avances عند الحاجة. |
| حساب الراتب | حساب salaire final حسب القواعد المعتمدة. |
| اعتماد التقرير | التقرير يبقى Brouillon إلى غاية الاعتماد. |
| الدفع | بعد الدفع تصبح الحالة Paye. |

## غلق الشهر

شروط الغلق:

- عدم وجود فروقات caisse غير مبررة.
- اكتمال بيانات الموردين والمتعاملين.
- اكتمال تقرير الرواتب.
- احتساب البيلان الشهري.
- مراجعة التقارير الأساسية.

نتيجة الغلق:

- الشهر يصبح `Cloture`.
- يمنع التعديل العادي.
- تبقى التقارير قابلة للطباعة والأرشفة.

# التوثيق العادي

يعرض هذا القسم البرنامج بلغة وظيفية عامة تناسب الإدارة، المحاسبة، والموارد البشرية. يشرح القسم الهدف من البرنامج، سير العمل، التقارير، والمصطلحات الأساسية.

## الملفات

| الملف | الغرض |
| --- | --- |
| [01-program-overview.md](./01-program-overview.md) | شرح عام للبرنامج، الوحدات، والمستفيدين. |
| [02-workflows.md](./02-workflows.md) | سير العمل اليومي والشهري بطريقة وظيفية. |
| [03-reports.md](./03-reports.md) | التقارير، الطباعة، والتصدير. |
| [04-glossary.md](./04-glossary.md) | قاموس المصطلحات العربية والفرنسية المستعملة في البرنامج. |

## نطاق القسم

- يشرح ما يفعله البرنامج.
- يشرح كيف تمر العمليات من الإدخال إلى التقرير.
- لا يعرض تفاصيل الحسابات الدقيقة أو شكل الواجهة التفصيلي.

# توثيق الواجهة وتنظيم العناصر

يعرض هذا القسم شكل الواجهة المتوقع وكيفية تنظيم العناصر داخل الشاشات. الهدف هو توحيد تصور الشاشة قبل التنفيذ، وتسهيل مراجعة التصميم من الإدارة والمحاسبة.

## الملفات

| الملف | الغرض |
| --- | --- |
| [01-screens.md](./01-screens.md) | وصف الشاشات الأساسية وما يظهر في كل شاشة. |
| [02-interface-organization.md](./02-interface-organization.md) | تنظيم عناصر الواجهة: الشريط العلوي، القائمة، الفلاتر، الجداول، الأزرار، والتفاصيل. |

## نطاق القسم

- يشرح شكل الشاشة وترتيب عناصرها.
- يوضح مكان الفلاتر والأزرار والجداول والمجاميع.
- لا يحدد ألوانا نهائية أو تقنية تصميم داخلية.

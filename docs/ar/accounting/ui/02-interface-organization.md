# 02 - تنظيم عناصر الواجهة

توثق هذه الوثيقة الشكل العام للواجهة وكيفية ترتيب العناصر داخل الشاشات. المقصود هو التنظيم الوظيفي للعناصر، وليس التصميم البصري النهائي.

## الهيكل العام للبرنامج

كل شاشة تتكون من مناطق ثابتة:

| المنطقة | الموقع | المحتوى |
| --- | --- | --- |
| الشريط العلوي | أعلى الشاشة | اسم البرنامج، الشهر والسنة، حالة الشهر، المستخدم الحالي. |
| القائمة الجانبية | جانب الشاشة | روابط الوحدات: Dashboard, Caisse, Coffre, Fournisseurs, Etats, DRH. |
| شريط الفلاتر | أعلى المحتوى | اختيار الشهر، السنة، الحالة، البحث، نوع التقرير. |
| منطقة العمل | وسط الشاشة | الجدول الرئيسي أو النموذج. |
| شريط الإجراءات | أعلى أو أسفل منطقة العمل | Nouveau, Enregistrer, Imprimer, Exporter, Historique. |
| منطقة المجاميع | أسفل الجداول المالية | Total, Reste, Difference, Profitabilite حسب الشاشة. |

## الشريط العلوي

يحتوي على:

- اسم ModernLam أو اسم البرنامج.
- الشهر والسنة المختاران.
- حالة الشهر: Ouvert, En revision, Cloture.
- اسم المستخدم الحالي.
- زر الخروج.

الغرض:

- معرفة الفترة الحالية في كل وقت.
- منع الخلط بين الأشهر.
- إظهار ما إذا كان الشهر قابلا للتعديل أو مغلقا.

## القائمة الجانبية

العناصر الأساسية:

| العنصر | الشاشة |
| --- | --- |
| Dashboard | ملخص الشهر والتنبيهات. |
| Cloture Caisse | مصاريف الصندوق والفروقات. |
| Caisse & Coffre | حركة الصندوق والخزنة. |
| Fournisseurs | الموردون والمدفوعات والبواقي. |
| Sous-Traitants | المتعاملون الخارجيون والاتفاقيات. |
| Presence | الحضور الشهري. |
| Salaires | تقرير الرواتب. |
| Etats | التقارير والطباعة. |
| DRH | الموظفون والعقود والعطل. |

## شريط الفلاتر

يوجد في أعلى أغلب الشاشات.

العناصر المعتادة:

- Mois.
- Annee.
- Statut.
- Recherche.
- Categorie.
- Fournisseur أو Employe عند الحاجة.

قواعد:

- يظهر الشهر والسنة في كل شاشة مالية أو إدارية.
- الفلاتر لا تغير البيانات، بل تغير طريقة العرض فقط.
- عند تغيير الفترة، يعاد تحميل بيانات الشاشة.

## الجداول

كل جدول مالي أو إداري يحتوي على:

- رأس أعمدة واضح.
- صفوف بيانات.
- عمود ملاحظات عند الحاجة.
- صف مجموع أسفل الجدول عند وجود مبالغ.
- حالة السجل عند الحاجة: Paye, Partiel, Impaye, Brouillon, Valide.

قواعد عرض الجداول:

- المبالغ تظهر في أعمدة مستقلة.
- الباقي `Reste` يظهر بجانب المبلغ المدفوع.
- الفروقات تظهر بوضوح في شاشة Differences.
- السجلات المغلقة تظهر للقراءة فقط.

## النماذج

النموذج يستعمل عند إضافة أو تعديل سجل.

العناصر:

- حقول البيانات.
- ملاحظات.
- مرفقات عند الحاجة.
- أزرار حفظ وإلغاء.
- تنبيه عند وجود نقص في حقل أساسي.

أمثلة:

- إضافة depense caisse.
- إضافة fournisseur.
- إضافة paiement.
- إضافة employe.
- إضافة contrat.

## تنظيم Dashboard

Dashboard ينقسم إلى:

| المنطقة | المحتوى |
| --- | --- |
| بطاقات الملخص | Caisse, Coffre, Chiffre d'Affaire, Profitabilite. |
| تنبيهات | فروقات، بواقي، رواتب غير معتمدة، شهر غير مغلق. |
| اختصارات | فتح Cloture Caisse، Fournisseurs، Presence، Etats. |
| ملخص الشهر | حالة الشهر وآخر تحديث. |

## تنظيم شاشة Cloture Caisse

المناطق:

1. فلتر الشهر والسنة.
2. Tab خاص بـ Depenses Caisse.
3. Tab خاص بـ Differences.
4. Tab خاص بـ Etat Differences.
5. مجموع المصاريف والفروقات أسفل الجداول.

## تنظيم شاشة Caisse & Coffre

المناطق:

1. جدول Mouvement Caisse اليومي.
2. جدول Entrees Supplementaires.
3. جدول Sorties Coffre.
4. جدول Mouvement Profitabilite.
5. ملخص Coffre Net Reel وChiffre d'Affaire.

## تنظيم شاشة Fournisseurs

المناطق:

1. قائمة الموردين أو الفئات.
2. جدول العمليات والفواتير.
3. جدول المدفوعات.
4. ملخص Total, Payer, Reste.
5. تفاصيل المورد عند اختيار سجل.

## تنظيم شاشة Presence

المناطق:

1. اختيار الشهر والسنة.
2. جدول الموظفين.
3. أعمدة أيام الشهر.
4. رموز الحضور.
5. مجاميع الموظف أو الشهر.

## تنظيم شاشة Salaires

المناطق:

1. اختيار الشهر والسنة.
2. جدول الموظفين والرواتب.
3. أعمدة الإضافات.
4. أعمدة الخصومات.
5. Salaire Final.
6. حالة التقرير: Brouillon, Valide, Paye.

## تنظيم شاشة Etats

المناطق:

1. اختيار نوع التقرير.
2. اختيار الفترة.
3. معاينة التقرير.
4. أزرار PDF وExcel وImprimer.
5. سجل النسخ الرسمية عند الحاجة.

## تنظيم شاشة DRH

المناطق:

1. قائمة الموظفين.
2. Fiche Employe.
3. Tabs: Identite, Contrat, Conges, Presence, Salaires, Documents.
4. تنبيهات العقود والعطل.

## حالات الواجهة

| الحالة | السلوك |
| --- | --- |
| Loading | ظهور مؤشر تحميل عند جلب البيانات. |
| Empty | رسالة تفيد بعدم وجود بيانات للفترة. |
| Read-only | تعطيل أزرار الحفظ عند غلق الشهر. |
| Error | عرض رسالة خطأ واضحة دون مصطلحات تقنية. |
| Saved | تأكيد حفظ العملية. |

## الطباعة والمعاينة

قبل الطباعة:

- تظهر معاينة التقرير.
- يظهر اسم التقرير والفترة.
- تظهر المجاميع.
- يظهر نوع النسخة: Draft أو Officiel.

بعد اعتماد نسخة رسمية:

- تحفظ عملية التصدير أو الطباعة في سجل التقارير.

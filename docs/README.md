## ملاحظات تنظيمية

- ضع التقارير الأصلية بصيغتها كما هي، مثل PDF أو DOCX أو XLSX.
- أضف ملخصا قصيرا لكل تقرير حتى يكون دوره واضحا.
- إذا كان التقرير يغير قاعدة حسابية أو شاشة في البرنامج، يجب ذكر ذلك في `README.md` الرئيسي أيضا.

# 02 - Navigation and Screen Structure

## General Structure

Each screen contains:

- Top bar: laboratory, period, status, user.
- Side menu: main modules.
- Content area: table, form, or report.
- Action bar: new, save, print, export, history.

## Side Menu

| Entry | Destination |
| --- | --- |
| Dashboard | Monthly summary. |
| Cash Closing | Cash expenses and differences. |
| Cash & Safe | Cash and safe movements. |
| Suppliers | Suppliers, invoices, payments. |
| Subcontractors | Subcontractors and conventions. |
| Attendance | Monthly attendance. |
| Salaries | Salary report. |
| Reports | Reports and printing. |
| HR | Employees, contracts, leave. |
| Administration | Users, permissions, audit. |

## Period

Fields:

- Month.
- Year.
- Status: Open, Under review, Closed.

Rules:

- Current month appears by default.
- Closed month is read-only.
- Yearly reports can use year only.

## Common Actions

| Action | Function |
| --- | --- |
| New | Create a record. |
| Save | Save. |
| Cancel | Cancel entry. |
| Delete | Delete or cancel according to permission. |
| Print | Print. |
| Export Excel | Excel export. |
| Export PDF | PDF export. |
| History | Element audit. |

## Record Statuses

| Status | Meaning |
| --- | --- |
| Draft | Not validated. |
| Validated | Validated and included in calculations. |
| Paid | Fully paid. |
| Partial | Partially paid. |
| Unpaid | Not paid. |
| Cancelled | Cancelled and excluded from calculations. |

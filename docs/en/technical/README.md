# Technical Documentation

The technical documentation is divided into two independent sections:

| Section | Link | Purpose |
| --- | --- | --- |
| General technical specifications | [specification/README.md](./specification/README.md) | General technical description: interfaces, rules, conceptual data model, permissions, reports, and general plan. |
| Implementation documentation | [implementation/README.md](./implementation/README.md) | Reserved space for practical implementation details according to the selected technology. |

## Boundaries

- The `specification` section does not depend on a specific framework or programming language.
- The `implementation` section will contain practical details: technology stack, project structure, final database schema, API, frontend, tests, deployment, and configuration.
- No precise implementation detail is fixed before the technology is selected.

## Relation to Accounting Documentation

The [accounting and administrative documentation](../accounting/README.md) describes the same scope in business language. This section covers technical and implementation aspects.

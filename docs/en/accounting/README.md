# Accounting and Administrative Documentation

This section is intended for accounting, direction, and human resources. It describes the software through three views: general documentation, accountant-readable technical accounting documentation, and interface documentation.

This section does not describe the internal database structure or programming details. Those elements are reserved for the [technical documentation](../technical/README.md).

## Sections

| Section | Link | Audience | Content |
| --- | --- | --- | --- |
| General documentation | [general/README.md](./general/README.md) | Direction, accounting, HR | Software purpose, workflows, reports, glossary. |
| Technical accounting documentation | [accounting-technical/README.md](./accounting-technical/README.md) | Accounting and financial direction | Stored data, calculations, differences, remaining balances, functional controls. |
| Interface documentation | [ui/README.md](./ui/README.md) | Direction, accounting, design | Screen organization, filters, tables, buttons, totals, printing. |

## Scope

- Description of operations visible to accounting and administration.
- Description of stored data and calculated results.
- Description of screen organization without programming details.
- No internal technical table names.

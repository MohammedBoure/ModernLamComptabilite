# Technical Accounting Documentation

This section presents the accounting details required to understand stored data, calculations, statuses, and controls. It remains readable for accounting users and does not use internal database structures.

## Files

| File | Purpose |
| --- | --- |
| [01-data-tables.md](./01-data-tables.md) | Functional tables and stored data. |
| [02-calculations-and-controls.md](./02-calculations-and-controls.md) | Calculations, controls, statuses, and accounting verification rules. |

## Scope

- Describes stored accounting data.
- Describes calculations: differences, remaining balances, profitability, salaries.
- Describes statuses: Paid, Partial, Unpaid.
- Does not describe the technical database structure.
